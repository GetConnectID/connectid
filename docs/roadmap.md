# ConnectID Roadmap

The ConnectID roadmap is intentionally evolutionary.

The project will develop through working functionality rather than promises.

## Phase 1 — Foundation

- Project definition
- Vision
- Identity concept
- Citizen concept
- Reputation concept
- Community concept
- Technical architecture
- Website foundation

## Phase 2 — Identity

- Identity architecture
- Citizen creation
- Citizen profile
- Basic identity management

## Phase 3 — Community

- Community interface
- Citizen discovery
- Communication
- Discussions
- Initial chat functionality

## Phase 4 — Reputation

- Contribution tracking
- Reputation model
- Reputation display
- Reputation mechanisms

## Phase 5 — Ecosystem

- ConnectID ecosystem integration
- CNID integration where appropriate
- Additional ecosystem functionality

## Phase 6 — Digital Society

Continue developing ConnectID toward the long-term vision of a parallel digital society.

## Status

The roadmap is subject to change as development and community feedback reveal what works.
