# ConnectID Profile

## Identity

Every ConnectID profile represents one ConnectID Identity.

## Public information

A profile may contain:

- avatar
- display name
- @username
- Citizen status
- role
- reputation
- connection information

## Optional wallet

Wallet information is optional.

The profile should not expose unnecessary blockchain information.

## Privacy

A legal name is not required to use ConnectID.

A virtual identity is allowed.

Users should be recognizable through their ConnectID history and behavior without being forced to publish their legal identity.

## Reputation

Reputation should be visible but subtle.

It should communicate accumulated trust rather than create a competitive leaderboard.

## Connections

ConnectID uses mutual connections rather than a follower model.

## Future profile features

Future versions may include:

- profile customization
- verification
- achievements
- reputation levels
- community participation
- media
- wallet verification
- privacy controls
