# ConnectID Website

This directory contains the ConnectID public website.

## Purpose

The website introduces:

- ConnectID
- The vision
- The Citizen concept
- Identity
- Reputation
- The community
- The ecosystem
- CNID

## Design direction

The website should remain:

- Clear
- Credible
- Simple
- Human
- Modern

The primary visual direction uses:

- Black
- White
- Orange

The website should communicate the idea without relying on excessive futuristic design.
