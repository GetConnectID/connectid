# ConnectID App

This directory contains the future ConnectID application.

The application will eventually provide the interactive environment for Citizens.

## Planned components

- Identity
- Citizen profiles
- Reputation
- Community
- Communication
- Chat

## Development principle

The application will be developed incrementally.

The architecture will be established before implementing the individual components.

The first practical goal is to create the foundation for a ConnectID Citizen.

The community and chat functionality will be built on top of that foundation.
