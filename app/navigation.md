# ConnectID Navigation

## Primary navigation

The ConnectID application should provide simple access to:

- Home
- Profile
- Connections
- Messages
- Communities

## Identity

The user's ConnectID identity should remain visible throughout the application.

## Messaging

Messages should remain easily accessible.

The experience should feel familiar to users of modern messaging applications.

## Communities

Communities should be accessible without replacing private messaging.

## Future navigation

Future features may include:

- Notifications
- Settings
- Search
- Wallet
- Reputation
- Verification

## Design principle

Navigation should remain simple.

ConnectID should not become a complex social-media dashboard.

The primary experience should remain:

Identity → Connections → Communication → Community
